# Get YouTube Videos (FreeAPI)

This is a simple React app that fetches and displays YouTube videos using a FreeAPI endpoint.

It shows:
- Thumbnail
- Title
- Channel Name
- Published Date
- Views
- Likes

> ⚠️ This project is part of the `freeapi-playground` repository. Make sure you are inside this folder before running.

## ▶️ Run This Project

```bash
git clone https://github.com/siddhantgorte/freeapi-playground.git
cd freeapi-playground/Freeapi-youtube-videos
npm install
npm run dev
