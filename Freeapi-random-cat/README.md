# Random Cat (FreeAPI)

This is a simple React app that fetches and displays a random cat using a FreeAPI endpoint.

> ⚠️ This project is part of the `freeapi-playground` repository. Make sure you are inside this folder before running.

## ▶️ Run This Project

```bash
git clone https://github.com/siddhantgorte/freeapi-playground.git
cd freeapi-playground/Freeapi-random-cat
npm install
npm run dev
